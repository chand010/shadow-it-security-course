# Module 02 — Discovery and Visibility

This module teaches authorized, proportionate and evidence-led discovery of unmanaged applications and data flows.

## Outcomes
- Define a written assessment scope and exclusions.
- Identify discovery sources and their limitations.
- Distinguish a lead, a validated observation and a confirmed exposure.
- Build an evidence register with provenance and confidence.
- Analyze synthetic DNS, proxy, endpoint, expense and OAuth events.
- Explain how Wireshark, Zeek, Wazuh, CASB and SaaS management platforms contribute to visibility.

## Safety
Only collect telemetry from systems and networks explicitly authorized for the assessment. This module's hands-on dataset is synthetic. Do not capture household, workplace or third-party traffic.
