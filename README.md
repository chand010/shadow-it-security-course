# Shadow IT Security Course

A practical course for discovering, assessing, governing and reducing Shadow IT risk. It combines Ubuntu/Docker labs, enterprise security platforms, Gartner research methods and a simulated court-sector assessment.

> **Public repository safety:** Use fictional identities, synthetic documents and lab-only infrastructure. Never commit real court records, personal data, credentials, API keys, environment files, internal IP inventories, production screenshots or live security findings.

## Learning outcomes
- Explain Shadow IT, its drivers, benefits and risks.
- Discover unmanaged SaaS and cloud usage using authorized methods.
- Assess cloud sharing, identity, privileged access and data exposure.
- Compare CASB, SSE, SASE, SSPM, SaaS management and DLP.
- Use Gartner research responsibly in vendor evaluation.
- Build an isolated Ubuntu/Docker lab and document evidence.
- Produce a risk register, prioritized recommendations and executive assessment.

## Learner lab profile
- OS: Ubuntu Linux
- RAM: 16 GB
- Docker: installed
- VirtualBox: installed

Start with the [lab setup guide](labs/UBUNTU_DOCKER_SETUP.md). Run one or two major services at a time.

## Module format
Each module includes concepts, tools, an isolated lab, a fictional court scenario, evidence tasks and a knowledge check. Do not mark a lab complete until it has been run and checked. Use statuses: planned, attempted, verified or blocked.

## Safety and authorization
Only inspect systems you own or are explicitly authorized to assess. Obtain written scope and approval before organizational discovery. Never place real court information or credentials in this public repository.

## Progress
The repository contains course materials; it does not imply local services have been installed or labs have passed. Publish only sanitized summaries.
